# Ecommerce Sales Analysis using SQL 📊

## Project Overview

This project focuses on analyzing ecommerce sales data using SQL to generate meaningful business insights.

The project demonstrates how raw sales data can be organized, analyzed, and transformed into useful information using relational databases and SQL queries.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Database Structure

The database consists of four relational tables:

### 1. Customers Table
Stores customer details such as:
- Customer ID
- Customer Name
- City
- State

### 2. Products Table
Stores product information:
- Product ID
- Product Name
- Category
- Price

### 3. Orders Table
Stores order transaction details:
- Order ID
- Customer ID
- Order Date
- Total Amount

### 4. Order_Items Table
Stores product-level order details:
- Order Item ID
- Order ID
- Product ID
- Quantity


## SQL Analysis Performed

The following business analyses were performed:

- Total sales revenue calculation
- Total number of orders analysis
- Average order value calculation
- Highest value orders identification
- Category-wise sales analysis
- Top-selling products analysis
- Customer spending analysis
- Monthly sales trend analysis


## Key Insights

- Total Sales Generated: ₹14,66,500
- Total Orders Analyzed: 100
- Average Order Value: ₹14,665

### Category Performance:
- Electronics generated the highest sales revenue
- Furniture contributed significant revenue
- Accessories had comparatively lower sales contribution

### Product Analysis:
- Identified top-selling products based on quantity sold

### Customer Analysis:
- Identified highest spending customers

### Sales Trend:
- Analyzed monthly sales performance to understand revenue patterns
